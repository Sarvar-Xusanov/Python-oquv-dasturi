# Lesson Content Standard — v2.0

Every v2.0 lesson package in `src/data/` is structured around:
1. **Identity & Metadata**: stable ID (`PY-*`), `courseId`, `moduleId`, `contentVersion`, `contentStatus`, difficulty, and `timeBreakdown` (explanation / examples / practice / review).
2. **Why It Matters**: concrete motivation tied to real software scenarios.
3. **Mental Model & Boundary**: intuitive everyday analogy paired with an explicit warning of where the analogy stops being accurate.
4. **Learning Outcomes**: measurable action-oriented objectives.
5. **Concept Explanation**: intuition first, then exact Python syntax and runtime behavior.
6. **Progressive Worked Examples**: simplest -> rule extension -> practical -> runtime verification, each runnable in the sandbox with deterministic `expectedOutput`.
7. **Execution Code Trace**: line-by-line state table showing variable mutations and stdout.
8. **Common Mistakes & Debugging**: buggy snippet, exact Python error symptom, root cause, corrected snippet, and prevention tip.
9. **Compare & Choose**: explicit decision criteria (`/` vs `//`, `for` vs `while`, `sep` vs `end`).
10. **Knowledge Check, Homework & Completion Criteria**: multi-question assessment, practical Code Lab homework with toggleable hint, and explicit mastery requirements.
